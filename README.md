# Legacy Brain brand assets

Public, finished Legacy Brain brand assets (logos, icons, images, email images), served at **https://assets.legacybrain.ai**.

- **Do not edit this repository by hand.** Files are published from the Legacy Brain master folders by the publish script, as a pull request. A publish goes live only when the pull request is merged.
- Addresses are permanent: anything here may already be used in sent emails. Removal is by the emergency takedown procedure only.
- Nothing here is a working file, unreleased design, client material or an unconsented photograph.
- `manifest.json` maps every address to its master file.

Owner: Legacy Brain.
